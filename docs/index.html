快速开始

克隆仓库后本地起一个静态服务：

python3 -m http.server 8000 → 访问 http://localhost:8000

或运行 python3 build.py 生成单文件 dist/ui-components.single.html。

实用组件套件（新增）

  • 侧边抽屉 — 左/右侧滑出，遮罩 + Esc 关闭
  • 搜索选择器 — 输入过滤、键盘选择、回车确认
  • 完整分页 — 省略号、上一页/下一页
  • 双滑块 — 区间选择，数值同步
  • 多类型 Toast — success / error / warn / info

主页锚点：#new-kit

复制组件代码

每个组件卡片右上角有 </> 按钮，可提取 HTML + 匹配的 CSS。带 JS 交互的组件会在注释里提示搜索关键字。
