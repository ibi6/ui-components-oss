# 交付前清单

从上到下走一遍；修完再查。只勾真正验证过的，不勾假设的。

## 结构与间距
- [ ] 每个间距值都来自 token，没有散落的 `13px`、`22px`。
- [ ] 组内 gap ≤ 组间 gap 的一半（看最密的一节）。
- [ ] 内容共享少数几条左边缘，没有"差不多对齐"。
- [ ] 父级用 `gap` 拥有间距；子元素不用 margin 推挤兄弟。

## 字体
- [ ] ≤ 2 字族、≤ 7 字号（全部来自 `--step-*`）、字重 ≤ 3 档。
- [ ] 行长在 `--measure` 内；长标题 `text-wrap: balance`。
- [ ] 表格/统计里的数字用 tabular 数字；单位在视觉上次于数值。
- [ ] CJK 正文行高 ≥ 1.7、不用斜体（用字重/颜色）、标点不孤行首。

## 颜色与表面
- [ ] 只有三档文字色；强调色只用于交互 + 一处关键强调。
- [ ] 文字对比 ≥ 4.5:1（大字与图标 3:1），明暗两套都达标。
- [ ] 分隔先留白；没有卡片同时叠 border + shadow + 有色填充。
- [ ] 圆角同心（外圆角 − padding = 内圆角）；圆角 ≤ 4 档。

## 状态
- [ ] 每个控件都有 hover（`@media (hover: hover)` 内）、`:focus-visible`、active、disabled。
- [ ] loading 用最终几何的骨架；空态说清下一步；错误说清发生了什么、怎么修。
- [ ] 破坏性操作视觉可区分，且与主操作保持间距。

## 响应式
- [ ] 320 / 360 / 390 / 768 / 1024 / 1440 / 1920：无横向滚动、无裁切。
- [ ] 200% 文字缩放可用；超长无空格字符串不破版。
- [ ] 触控目标 ≥ 40px；固定条尊重安全区。

## 动效
- [ ] 每个动画回答一个问题；每视图一个 hero moment；ambient 循环 ≤ 2。
- [ ] 只动 `transform`/`opacity`；时长与缓动来自 tokens；无 `transition: all`。
- [ ] `prefers-reduced-motion` 去掉行程与循环、保留状态信息。
- [ ] 无 JS 或动画未完成时内容可见。
- [ ] 定义了 `from` 的 keyframes 都有显式 `to`；带内联初始态（opacity:0 等）的元素动画结束后可见。
- [ ] 静态内容没有模拟流式/思考步骤（即内容与呈现同时到达）。
- [ ] 动态拼接的文案（含变量插值）在浏览器里见过实际渲染值，没有 undefined 泄漏到界面。
- [ ] 用 `display:flex/grid` 等覆盖了元素默认 display 的容器，`hidden` 属性仍生效（`.x[hidden]{display:none}`）。

## 流式
- [ ] pending / streaming / done / error / aborted 每个状态都截图见过，不是想象。
- [ ] 内容到达零布局位移；Stop 与重试键盘可达；失败保留已读内容。

## 收尾
- [ ] 删掉一个装饰元素，确认无损失。
- [ ] 文案过一遍：按钮用动词、概念同名、无填充句。
- [ ] 有意横向滚动的容器标了 `class="scroller"`（audit 豁免标记）；无意滚动已消除。
- [ ] 有色底（强调色 tint / 深色墨底）上的文字按实际混合底色验证过对比度，深浅两套都查。
- [ ] 运行 `scripts/audit.mjs`，exit code 0。
